# Database

MySQL 8.0 migrations, seed data, and helper scripts.

## Layout

| Path                                              | Contents                                                                       |
| ------------------------------------------------- | ------------------------------------------------------------------------------ |
| `migrations/`                                     | Numbered `001`–`009` SQL files that create the schema, applied in order        |
| `seeds/default/`, `seeds/minimal/`, `seeds/full/` | The three seed profiles                                                        |
| `scripts/init.sh [seed_type]`                     | Rebuilds `docker-entrypoint-initdb.d/` from migrations + one seed profile      |
| `scripts/reset.sh`                                | Stops containers and drops the MySQL volume                                    |
| `docker-entrypoint-initdb.d/`                     | Generated by `init.sh`; used by plain `docker compose up`                      |
| `init/minimal/`, `init/full/`                     | Pre-combined migrations + seed, committed as-is, used by the compose overrides |
| `prod-initdb.d/`                                  | Migrations + the gitignored production seed + the read-only-user script        |

## Commands

```bash
cd database/scripts
./init.sh default    # or minimal, full — rebuild docker-entrypoint-initdb.d
./reset.sh            # drop the MySQL volume before switching seed profiles
```

Both only take effect against a fresh MySQL volume — run `reset.sh` before `init.sh` if a stack is already running.
